# Performance Baseline

The versioned baseline is generated by:

```powershell
.\scripts\benchmark.ps1
```

It runs 1, 3, and 5 concurrent isolated sessions and records session creation, first navigation, snapshot, queue wait, cleanup, memory context, and failure rate in `benchmarks/baseline.json`.

The checked-in baseline is a real measurement from the target Windows host:

| Concurrency | Create avg | Navigate avg | Snapshot avg | Cleanup avg | Failures |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 1947.52 ms | 786.46 ms | 362.95 ms | 955.89 ms | 0 |
| 3 | 4683.72 ms | 2664.20 ms | 932.53 ms | 2631.93 ms | 0 |
| 5 | 8418.88 ms | 5093.00 ms | 2631.90 ms | 9930.08 ms | 0 |

Queue wait was zero at every tested concurrency. Compare future changes under equivalent host and workload conditions. When run from an immutable deployment snapshot, the benchmark writes `baseline-current.json` to the V2 runtime QA directory rather than changing deployed source files.
